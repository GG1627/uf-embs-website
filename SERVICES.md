# Services We Use

This is a simple list of services/tools used by the IEEE EMBS website and related projects. The goal is to help new members know what accounts or access they may need.

## Supabase

Link: https://supabase.com/

Why/how we use it: Database, auth, storage, and backend functions for the website.

## Vercel

Link: https://vercel.com/login

Why/how we use it: Hosts and deploys the website.

## Resend

Link: https://resend.com/

Why/how we use it: Sends emails from the website, like contact or feedback messages.

## Cloudflare Turnstile

Link: https://www.cloudflare.com/products/turnstile/

Why/how we use it: CAPTCHA / bot protection used by the Discord bot.

## Groq

Link: https://groq.com/

Why/how we use it: LLM API for AI chat bot on the website.

## Namecheap

Link: https://www.namecheap.com/

Why/how we use it: Website domain name.

## Google Calendar / Google API

Link: https://console.cloud.google.com/

Why/how we use it: Calendar and event-related features.

## EMBS Discord Bot

Repo: https://github.com/GG1627/uf-embs-discord-bot

Why/how we use it: Discord bot for EMBS. Seperate Repo (probably wont need it tbh)

## Fly.io

Link: https://fly.io/

Why/how we use it: Deploys the EMBS Discord bot.

## EMBS ML Attendance Model

Repo: https://github.com/GG1627/uf-embs-ml

Why/how we use it: Attendance prediction model. Seperate Repo (probably wont need it tbh)

## Render

Link: https://render.com/

Why/how we use it: Deploys the ML attendance prediction model.

## UptimeRobot

Link: https://uptimerobot.com/

Why/how we use it: Pings the ML attendance model so it stays awake.
